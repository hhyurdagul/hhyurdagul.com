# hhyurdagul.com

Personal website built with [Zola](https://www.getzola.org/).

```sh
nix develop
zola serve             # local preview; add --drafts to include drafts
zola build             # outputs to public/
nix run .#og-cards     # regenerate the social preview image
```

Content lives in `content/`; CV engagements in `data/consultancies.json`.
Interactive demos are self-contained HTML in `demos/`, inlined into a page with
the `demo` shortcode (`{{ demo(name="mdsai") }}`); they are not published on their own.
System diagrams are HTML, not images: `{{ pipeline(src="pipeline.toml") }}` renders the
steps listed in a TOML file next to the page, so they follow the theme.
Project cards use `extra.card_image` when set, otherwise `extra.screenshot`. The MdsAI
card cover is generated by `scripts/mdsai-card.py` (run instructions in the file); rerun it
when its headline number changes, then delete its old copy in `static/processed_images/`.
`archive/` holds unpublished material. It is excluded from the build but still public in the repo.

Pushes to `master` deploy to GitHub Pages.
